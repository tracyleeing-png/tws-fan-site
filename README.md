# 24/7 WITH TWS

一个为 TWS 与 42 制作的响应式非官方粉丝网站。

## 打开方式

直接双击 `index.html` 即可浏览。若使用 IDE，也可以通过任意静态网页服务器运行。

## 页面内容

- 使用提供的海边照片，并随本地时间变化的首页昼夜氛围
- 与当前时刻同步的数字时钟、模拟时钟和 24 小时进度
- 六位成员详细资料卡与 42 介绍
- 按发行日期排列的完整唱片架
- 心情选歌互动
- 带相关页面链接的 TWS 历程时间线
- 使用浏览器本地存储的 42 留言墙
- 桌面与手机端响应式布局

## 文件结构

- `index.html`：页面结构与内容
- `styles.css`：视觉、动效和响应式布局
- `script.js`：时间主题、弹窗、选歌与留言交互
- `assets/home-beach-*.png`：首页照片
- `assets/final-*.png`：尾页照片
- `assets/favicon.svg`：网站图标

本项目为非官方粉丝创作，与 PLEDIS Entertainment 或 HYBE 无隶属关系。站内作品与历程链接优先指向官方渠道，成员词条链接指向中文维基百科。
